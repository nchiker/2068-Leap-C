# Leap-C 1.0.0-beta.1 — public beta

**A C computer for the Timex Sinclair 2068.** Leap-C replaces the TS2068's two ROMs with a full-screen C editor and a C compiler that runs on the machine: type a program, `RUN` compiles it to native Z80 code (about 13 ms a line) and runs it. This is the first public release, a **beta for testing on emulators**. Release 1.0 follows the beta's feedback.

**Start here:** [docs/EMULATORS.md](https://github.com/nchiker/2068-Leap-C/blob/v1.0.0-beta.1/docs/EMULATORS.md) (setting up Fuse, ZEsarUX or TSRun), [docs/USER_GUIDE.md](https://github.com/nchiker/2068-Leap-C/blob/v1.0.0-beta.1/docs/USER_GUIDE.md), [docs/BETA_TESTING.md](https://github.com/nchiker/2068-Leap-C/blob/v1.0.0-beta.1/docs/BETA_TESTING.md). No install at all: [run it in your browser](https://nchiker.github.io/TSRun/?rom=leapc) (TSRun; tapes do not load there).

## What Leap-C does

- **The language:** a documented subset of C89: `char` (unsigned), `int`, `unsigned`, pointers, multi-dimensional arrays, `struct`, `enum`, `typedef`, pointers to functions, recursion, every operator and statement (`switch`, `goto` too), static initialisers, `#define`, and `float`/`double` in the Sinclair 5-byte format with `printf("%f")`. Anything outside the subset is a compile error (`NOT SUPPORTED`), never a miscompilation.
- **The library**, built in, no `#include`: text, colour and `printf`; the keyboard (`getkey`, `inkey`, `gets`); graphics (`plot`, `draw`, `point`, sprites, the hi-res colour mode); the AY sound chip (`beep`, `sound`); `frames`, `pause`, `rand`; strings and memory; `malloc`/`free`; ports; cassette data (`tape_save`, `tape_load`). 50 functions.
- **Libraries from tape:** `LIB "shapes"` loads an assembly library (1 KB) whose functions are then called like the built-in ones; 16 fixed ROM service slots keep libraries working across ROM updates. Example: `shapes` (`circle`, `box`, `isqrt`).
- **The editor:** full screen, lines up to 127 characters that wrap, C keywords in bold, the C characters the TS2068 lacks on SYMBOL SHIFT + Y U F G S A H D (`[ ] { } | ~ ^ \`), compile errors that put the cursor on the error's column, runtime errors and BREAK reported at the failing function's line.
- **Cassette:** `SAVE`, `LOAD`, `VERIFY` of program source in the TS2068's standard signal, with Leap-C's own version word; `tools/c2tape.py` makes a tape from a `.c` file on a PC.
- **Capacity** on a 48 KB TS2068: about 18 KB of source, 19 KB of compiled code and data, recursion 190 levels deep for a typical function, a heap of up to 18 KB.

## How it was qualified

On **Fuse 1.9.1** (unmodified; the TS2068's real 60 Hz frame) and **ZEsarUX 13.0 with an EXROM patch** (50 Hz), headless:

- the executable corpus (719 C programs with checked results, the documentation's 34 examples among them) compiled and run directly, through the shell's `RUN`, under a RAM canary and banking invariants, and from random and fixed power-on memory; 215 declaration and 113 lexer cases; the float core against a bit-exact model (5,451 cases);
- on Fuse, 780 corpus programs LOADed from their tapes by Leap-C's own loader and RUN; typed programs, BREAK, `SAVE` recorded and loaded back, the library from tape;
- the editor and shell (every C character typed through the keyboard matrix), the cassette on real tape signals both ways, a 30-minute soak, the measured capacity;
- ROM coverage: 99.8% of HOME's and 99.4% of the EXROM's instructions executed;
- reproducible builds; CI builds every commit.

The per-phase reports, with every measurement, are in [docs/milestones/](https://github.com/nchiker/2068-Leap-C/tree/v1.0.0-beta.1/docs/milestones).

## Known limitations

- **Not yet run on a physical TS2068.** The hardware kit and checklist are ready; results are very welcome.
- **ZEsarUX:** the downloadable ZEsarUX 13.0 shows a blank screen: build 13.0 with Leap V2's small EXROM patch ([EMULATORS.md §3](https://github.com/nchiker/2068-Leap-C/blob/v1.0.0-beta.1/docs/EMULATORS.md#3-zesarux-130-with-the-exrom-patch)), or use Fuse. ZEsarUX cannot write `SAVE` to a tape file, and runs the TS2068 at 50 Hz (timings in frames 20% longer).
- **TSRun** (browser): tapes do not load; `SAVE` cannot be recorded.
- **The language:** no `long`, `union`, `volatile`, struct parameters, returns or assignment, initialisers on local arrays or structs, function-like macros, `#if`, user variadic functions, maths library, or `printf` flags and `%e`/`%g`. Integer division by zero gives 0. `float` is not IEEE.
- **Keyboard legends:** the keys for `[ ] { } | ~ ^ \` show BASIC keywords on a real TS2068.
- Leap-C reads only its own tapes (TS2068 BASIC and Leap V2 tapes give `BAD TAPE VERSION`).
- Other emulators are untested.
