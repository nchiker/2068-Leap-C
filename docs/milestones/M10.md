## 4. Library loading (Stage 1)

The report's plan, Stage 1: **a library needs no new syntax, only a table of functions the compiler's existing binding searches.** A library function is called exactly like `printf`: a `call` to a fixed address with the C calling convention.

### 4.1 The image and the ABI

A library is an image for image region 3 (`$F400-$F7FF`, at most 1 KB): a header (the magic `$8D`, the ABI version, the export count), the export table in `LIB_NAMES`'s records (the name, its last character with bit 7 set; the address; the signature byte), a 0, then code and data. **`include/leapc_lib.inc` is the single source of truth**, included three ways, after V2's package ABI (`include/v2_package_abi.inc` at the V2 tag): HOME assembles the slots' `jp`s from it and `ASSERT`s every pin against its own symbols; the EXROM takes its constants; a library's source gets each slot's address and each pin's value, and can name nothing else of the ROM.

The signature byte is `[return type:4][parameter list:4]`, as for the ROM's library: the return type's bases are `include/leapc_decl.inc`'s (`void`, `char`, `int`, `unsigned`, `float`, and `void *`, `char *`), and the parameter list indexes the ROM's `LIB_PARAMS`, which gained four lists for libraries (`(int, int, int)`, `(int, void *)`, `(int, int, void *)`, five ints): all 16 entries are now valid, and their order is part of the ABI.

### 4.2 The jump table (owner decision: V2-style slots)

16 slots of `jp`, 48 B at `$3FD0-$3FFF`, the end of HOME: a component pinned above the code (`tools/budget.py`), so the code can grow without moving it. The services, chosen for what a library needs (`spec.md` §2.4 has each slot's contract):

| Slots | Services |
|---|---|
| 0 `LX_ARGS` | the arguments, and the program's call recorded for errors and BREAK |
| 1-2 `LX_PUTC`, `LX_PUTS` | character and string output at the print position |
| 3-4 `LX_MALLOC`, `LX_FREE` | the heap |
| 5-7 `LX_MUL`, `LX_DIVS`, `LX_DIVU` | the integer helpers |
| 8 `LX_FOP` | the float core on `F_ACC` |
| 9 `LX_ERROR` | the runtime error exit |
| 10-12 `LX_KEY`, `LX_INKEY`, `LX_FRAMES` | key and frame reads |
| 13 `LX_PLOT` | a pixel |
| 14-15 | reserved: runtime error 4 |

**Rules:** a slot is never reordered or repurposed; a new service takes a reserved slot and raises the ABI version, which `LIB` checks; anything else needs a new magic. **No slot serves the editor engine**: Fix 4 removed its fallbacks for unset hooks. Pinned: `F_ACC`, `LIB_COL`, `LIB_ROW`, `LIB_ATTR`, three runtime errors and twelve float operations.

### 4.3 The tape and `LIB`

A library tape is a program tape's two blocks with header type 4 (V2's package type) and the image's magic and ABI as the version word (`$8D01`). **The platform's own version check refuses a wrong magic or a later ABI at the header, before a byte is stored:** `STORAGE_VERSION_WORD`'s package branch, V2's, gives the library word for type 4 (so Fix 4 keeps it). `LIB "name"` (or `LIB ""`) loads through the existing tape path: the image arrives above the source when there is room and moves into the region once whole, as LOAD's program does, else straight into the region; the report is `LIBRARY name: n FUNCTIONS` (row 23: `SOURCE s B  FREE f B`), or `BAD TAPE VERSION`, `LOAD FAILED`, `BREAK`, `BAD NAME`. A failure that wrote into the region leaves no library; any other keeps the one before. `LIB` alone unloads it (`NO LIBRARY`). **Decided: `NEW` and `LOAD` keep the library** (it belongs to the session; a program LOADed from tape can use it at once; V2's `NEW` unloaded its package); **a reset clears it.**

### 4.4 The compiler and the runtime

- **Region 3 closed:** while `LIB_LOADED` is set, `CC_COMPILE` makes the region full (`[end][end]`), as `#pragma hires` does region 4: what it would have held goes to region 4 (`tests/lib/loaded/region3.c` and its twin `region3_open.c`). `IMAGE` leaves it out.
- **Binding:** an identifier no declaration names is looked up in the ROM's table, then the library's, by the same search (`LIB_FIND`) and the same binding (`XL_BIND`), and calls are checked against the signature's prototype (`WRONG ARGUMENT COUNT`, `TYPE MISMATCH`: `tests/lib/loaded/err/`). **A name both have binds the ROM's** (the test library exports `abs`; `abs()` is the ROM's: `collision.c`); a program's own declaration hides either (`hidden.c`); without the library a call is `UNDEFINED FUNCTION` with its name (`err/unloaded.c`).
- **BREAK and runtime errors** inside a library behave as inside the ROM's library: reported at the program's call into the library (`LIB_CALLER`), whether they arise in the library's own code (`break_lib.c`: BREAK in its loop in region 3, the interrupted PC checked) or in a service it called (`break_service.c`, BREAK while `LX_KEY` waits; `float_error.c`, error 6 in `LX_FOP`; `error.c`, `LX_ERROR`; `reserved.c`, a reserved slot).
- **The canary:** with a library loaded, the compile must leave its image exactly as it was, and at run time the region is the library's own RAM, as the ROM library's cells are; the canary and the banking invariants pass on every library case. The stack: a library function uses no more than the ROM's library (measured, `spec.md` §7.2: 40 B below its argument for a scrolling print, the ROM's `puts()` 42 B).

## 5. Defects found

### 5.1 A LOAD stopped by BREAK kept a partly overwritten source (Phase 7)

A LOAD whose program does not fit above the current source receives it straight into the line store. `SH_LOAD_IO` turned every failure with SPACE held into a plain `TR_BREAK`, losing `STORAGE_LOAD`'s "part of the data block was written". BREAK during that data block was therefore reported as BREAK, and the source, partly overwritten, was kept: records of the tape's program over the start of the old source, with the old `PROG_END`. Found while reusing the tape path for `LIB`. **Fix (ledger L67, +4 B):** `SH_LOAD_IO` returns `TR_BREAKT` for a BREAK once data was written (an `add` in place of an `ld`), which LOAD treats as written (the source is emptied, V2's rule) and `LIB` as written (no library is left loaded); both are still reported as BREAK, and `tape_load()` ends the program with BREAK either way. **Test:** the cassette suite's `load-break-direct` passes; on a build with only this fix reverted it fails, its source holding the tape's first record merged into the old lines.

### 5.2 Fix 2's prototype named the wrong identifier for a `#define` defined twice

The directive processor never sets `NM`, so `ALREADY DEFINED` for a macro defined twice showed whatever identifier the compiler had last looked up: `int total;` then `#define N` twice gave `LINE 5  'total'`. The prototype's tests passed because their `#define`s came first, and the harness accepted any word of the source. **Fix (ledger L75, +6 B EXROM):** `PP_DEFINE` clears `NM_LEN` on that error, so a `#define`'s `ALREADY DEFINED` shows no name, as approved. **Tests:** `tests/pperr/redefine_after_code.c`; the harness now requires a reported name to be a word of the error's line or of a `#define`, and all 28 corpus cases of the five errors pass under it.

## 10. Code audit

- **The slots.** Each `jp` is assembled from `include/leapc_lib.inc` with an `ASSERT` on its address; the table is the last 48 bytes of HOME, a pinned budget component, and the test image must equal production there (`tools/check_test_image.py`). The pins `ASSERT` the ROM's own symbols. The reserved slots jump to `RT_ERR_ARG`.
- **The services keep `LIB_CALLER`.** Every slot but `LX_ARGS` leaves it alone: `LX_FOP` is `F_X`, not `F_OP` (which records its caller); `LX_MALLOC`, `LX_FREE` and `LX_PLOT` enter after `LIB_ARGS`. So an error or BREAK in a service is reported at the program's call into the library.
- **`RT_BREAKREQ`.** `LIB_LOADED` is `$F4` or 0, so `dec a / cp h` makes every PC at or above `$F400` the library's when one is loaded, and none otherwise; image region 3 holds no program code while a library is loaded (`CC_COMPILE` closes it), and `$F800` up is the stack.
- **`CC_COMPILE`.** One byte written: region 3's `[low]` high byte, `$F4` → `$F8`, after the region table is copied; `IMAGE` leaves the closed region out (`SH_IMAGE`).
- **`LIB_FIND`.** After the ROM's table's 0, bit 5 of the pointer's high byte tells the EXROM's table (`$C0-$DF`: clear) from the library's (`$F4-$F7`: set), asserted; the library's table is searched only while `LIB_LOADED` is set, with the same loop, and a malformed table ends at its first 0.
- **`SH_LIB`.** Staged above the source when there is room (`SH_TAPE_HOOK`, shared with LOAD through `SH_LOAD_AT`), copied into the region only when whole; `LIB_LOADED` is cleared only when the region was written by a failed transfer. The report's longest text, 10 characters of name and a two-digit count, is 32 characters: `tools/lib2tape.py` refuses more than 99 exports, and a forged tape's NUL would land on `SH_ERR_COL`'s low byte, which is 0 then (asserted adjacent).
- **The pattern scan** (`make audit`) over the changed code finds only hints that are not defects: the `ei` before `ret` in `SH_TAPE_OFF` (the one `SH_TAPE_DONE` had inline: interrupts are on at the return, as before), the page-local constants (`LX_BASE >> 8`, `LIB_PARAMS`' page: asserted), and the region-3 limit store in `CC_COMPILE` (a cell, not code).

## 11. Limitations and remaining risks

- **Physical hardware**: still the owner-accepted deviation of Phase 9; the kit adds the library tape and H11 (checklist 7.6-7.8).
- **A library is trusted code.** It runs with the program's privileges and can corrupt anything; the ROM checks its tape's magic, ABI and checksums, not its code. `tools/lib2tape.py` checks the image's structure.
- **No float parameters in a signature**: a library function with float arguments must be declared without a prototype (list 0).
- **Stage 2** (libraries written in C on the machine) is not built.
- **Reserves:** HOME 71 B above its floor, EXROM 58 B.
